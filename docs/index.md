# Laravel API Tool Kit - maintained fork

Version 4 supports maintained PHP 8.2-8.5 and Laravel 12/13. This fork incorporates upstream changes while retaining its enum casts, route/table naming, and unguarded model scaffolding.

The [current package guide](https://github.com/awais-afoxtech/laravel-api-tool-kit/blob/master/Readme.md) is the canonical documentation. Read the [migration guide](https://github.com/awais-afoxtech/laravel-api-tool-kit/blob/master/MIGRATION.md) and [changelog](https://github.com/awais-afoxtech/laravel-api-tool-kit/blob/master/CHANGELOG.md) before upgrading.

The Composer identity is `essa/api_tool_kit`. Configure the fork repository and a published fork tag; upstream Packagist does not automatically serve fork releases. The guide covers responses/errors, safe regeneration, filters/pagination, media, enum compatibility, and optional AI rules.
